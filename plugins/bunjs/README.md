# bunjs

Bun and TypeScript toolkit for Claude Code. Install from the `magus` marketplace.

## `opentui-tui`

Build, review or debug OpenTUI terminal UIs: React JSX intrinsics, Yoga flexbox, the five single-row visuals
(gradient meter, sparkline, heat row, badge, panel) as tested code you copy into your project, a measured pin and
build matrix by artifact, and a colour-accurate screenshot loop that lets an agent see its own UI. Only Bun is
tested; Node and Deno at your own risk.

Run **`/bunjs:opentui-tui`**. The skill is deliberately out of the model's skill listing, so that command is how it
gets found — and the routing row for a project `CLAUDE.md` is: *Bun/TypeScript terminal UI — OpenTUI, dashboards,
TUI review → `/bunjs:opentui-tui`, before writing or reviewing any OpenTUI component, screen or theme.* Other
Bun-wide skills may land here later.
